# План: браузерная 3D-гонка «Неоновый трек»

Оригинальная аркадная 3D-гонка в браузере: 1 игрок против 3 ботов, 3 круга по замкнутой трассе.
План составлен Opus, код пишет Sonnet по этому документу.

## 1. Технологии

- **Three.js 0.160.0** через `importmap` с `https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js`.
- Чистый JavaScript (ES-модули), **без сборщика**, без npm-зависимостей для самой игры.
- **Никаких внешних моделей/текстур** — всё строится из примитивов Three.js (Box, Cylinder, Cone) и процедурной геометрии.
- Своя упрощённая аркадная физика (без физических библиотек). Трасса плоская (y = 0).
- Запуск: `python3 -m http.server 8000` в корне → `http://localhost:8000`.

## 3. Игровой цикл и состояния (`main.js`)

Состояния: `MENU → COUNTDOWN (3..2..1..GO) → RACING → FINISHED`, плюс `PAUSED` (Esc) поверх RACING.

```
loop(now):
  dt = min((now - last)/1000, 0.05)
  if state == RACING:
     input → player.update(dt, controls)
     для каждого бота: ai.getControls(bot) → bot.update(dt, controls)
     resolveCarCollisions(cars)
     race.update(cars, dt)
     if race.playerFinished → state = FINISHED
  camera.update(player, dt)   // и в COUNTDOWN тоже
  hud.update(...)
  renderer.render(scene, camera)
```

В COUNTDOWN машины стоят на стартовой решётке, газ не работает.
Экран FINISHED: итоговое место, общее время, лучший круг, кнопка «Ещё раз» (сброс всех систем без перезагрузки страницы).

Отладочный хук для тестов: `window.__game = { state, player, cars, race }`.

## 4. Трасса (`track.js`)

- Задаётся ~12–16 контрольными точками на плоскости XZ (масштаб ~ 400×300 м), формирующими интересный замкнутый контур: длинная прямая со стартом, шпилька, связка S-поворотов, быстрая дуга.
- `curve = new THREE.CatmullRomCurve3(points, true, 'centripetal')`.
- Сэмплирование: `N = 1000` точек `samples[i] = {pos, tangent, normal, }`, где `normal` — перпендикуляр к касательной в плоскости XZ.
- **Дорога**: лента (BufferGeometry) из пар вершин `pos ± normal * halfWidth`, `halfWidth = 7`. Тёмный асфальт, белые/красные бордюры — отдельные ленты по краям, разметка по центру пунктиром.
- **Стартовая линия**: шахматная полоса в `samples[0]`.
- **Отбойники**: невысокие стенки (ленты-экструзии) на расстоянии `wallOffset = halfWidth + 4` от центра.
- API:
  - `findNearest(pos, hintIndex)` → `{index, distance (signed, по normal), point}`; поиск локально в окне ±40 сэмплов вокруг `hintIndex` с переходом через 0 (быстро), при `hintIndex == null` — полный перебор.
  - `getSample(i)` с зацикливанием индекса.
  - `getStartGrid(slot)` → позиция и heading для слота 0..3 (решётка 2×2 позади стартовой линии).
  - `points2D` для мини-карты.

## 5. Машина и физика (`car.js`)

Модель из примитивов: корпус (Box), кабина (Box, тёмное стекло), 4 колеса (Cylinder, передние поворачиваются визуально), фары (emissive). Цвет задаётся параметром. Размер ~ 2 × 1 × 4 м.

Состояние: `position (Vector3)`, `heading (рад, 0 = +Z)`, `velocity (Vector3, мировая, y=0)`, `trackIndex`, `steerVisual`.

Управление (`controls`): `{ throttle: 0..1, brake: 0..1, steer: -1..1, handbrake: bool }`.

Шаг физики `update(dt, controls)`:
1. `forward = (sin h, 0, cos h)`, `right = (cos h, 0, -sin h)`.
2. Разложить скорость: `vF = v·forward`, `vL = v·right`.
3. Газ: `vF += accel * throttle * dt` (accel = 22). Тормоз: если `vF > 0.5` — `vF -= brakeForce * brake * dt` (40), иначе задний ход до `-maxReverse` (10).
4. Сопротивление: `vF -= vF * drag * dt` (drag 0.25) + rolling `0.8 * sign(vF) * dt`; ограничение `maxSpeed` (58 м/с ≈ 210 км/ч).
5. Руление: `steerRate = maxSteer(2.2 рад/с) * steer * clamp(|vF|/8, 0, 1) * (1 - 0.45 * |vF|/maxSpeed)`; при движении назад знак инвертируется. `heading += steerRate * dt`.
6. Сцепление (дрифт): `vL *= exp(-grip * dt)`, `grip = 9`, при `handbrake` → `1.8` и доп. торможение `vF *= 1 - 0.6*dt`.
7. Собрать `v = forward*vF + right*vL`, `position += v*dt`.
8. Трасса: `findNearest`. Если `|distance| > halfWidth` (обочина) — `maxSpeed` эффективно ×0.45 и доп. drag. Если `|distance| > wallOffset - 1` — вытолкнуть позицию обратно на `wallOffset - 1` по normal, погасить нормальную к стене составляющую скорости, общую скорость ×0.6.
9. Обновить меш: позиция, `rotation.y = heading`, лёгкий крен кузова от `vL`, вращение колёс по `vF`.

Геттер `speedKmh = |vF| * 3.6`.

Столкновения машин (`resolveCarCollisions` в car.js): машины как окружности радиуса 1.6; при пересечении раздвинуть пополам и обменять/погасить составляющую скорости вдоль линии центров (коэффициент 0.5).

## 6. ИИ ботов (`ai.js`)

- Каждый бот имеет параметры: `skill` (0.85..1.0 → множитель максимальной скорости), `laneOffset` (-2..2 м, смещение от центра, медленно «плавает» синусом), `lookahead` (12..18 сэмплов).
- `getControls(bot)`:
  1. Цель = `samples[bot.trackIndex + lookahead] + normal * laneOffset`.
  2. Угол до цели в локальной системе машины → `steer = clamp(angleDiff * 2.5, -1, 1)`.
  3. Кривизна впереди: угол между касательными на `+10` и `+40` сэмплов. Целевая скорость `= maxSpeed * skill * lerp(1, 0.55, curvature/1.2)`.
  4. `throttle = 1` если скорость < целевой, иначе `brake` пропорционально превышению.
  5. Застревание: если скорость < 2 м/с дольше 2 с во время гонки — сбросить бота на ближайшую точку трассы с правильным heading.
- Резиновая лента (лёгкая): если бот далеко впереди игрока (>0.15 круга) — skill ×0.95, сильно позади — ×1.05.

## 7. Гонка (`race.js`)

- `laps = 3`. Для каждой машины: `lap`, `nextCheckpoint`, `lapStartTime`, `lapTimes[]`, `finished`, `finishTime`.
- Чекпоинты — индексы сэмплов `[250, 500, 750]` + финиш `0`. Чекпоинт засчитывается, когда `trackIndex` попадает в окно `[cp, cp+30]` и он следующий по порядку. Круг засчитывается при прохождении индекса 0 (переход `index > 900 → index < 100`) после всех чекпоинтов. Это защищает от «срезания» и езды задом через финиш.
- Прогресс для сортировки мест: `lap + checkpointsPassed*0.25 + ...` — проще: `progress = lap * N + (index относительно старта с учётом пройденных чекпоинтов)`. Финишировавшие сортируются по `finishTime`.
- Отдаёт: `getPosition(car)`, `getLap(car)`, `currentLapTime`, `bestLap`, `totalTime`, `wrongWay` (если heading игрока против касательной > 120° при скорости > 5 — показать «НЕ ТУДА»).
- После финиша игрока боты, не успевшие доехать, получают места по текущему прогрессу.

## 8. Камера (`camera.js`)

PerspectiveCamera FOV 65 (+до 10 при высокой скорости для ощущения скорости).
Желаемая позиция = `car.position - forward * 9 + up * 4`; плавно `lerp` с коэффициентом `1 - exp(-6*dt)`. `lookAt(car.position + forward*5 + up*1)`. Клавиша **C** — переключение на вид с капота.

## 9. HUD (`hud.js`) и меню

- Спидометр (км/ч, крупно, внизу справа), «Круг 2/3», «Место 1/4», текущее время круга, лучший круг.
- Мини-карта: 2D canvas 180×180 вверху справа, линия трассы из `points2D` (нормализованных в квадрат), точки машин их цветами, игрок крупнее.
- Центральные сообщения: отсчёт «3 / 2 / 1 / СТАРТ!», «Последний круг!», «НЕ ТУДА», «ПАУЗА».
- Меню (DOM): название, кнопка «Старт», описание управления.

## 10. Мир (`world.js`)

- Тёмно-синее вечернее небо (`scene.background` + `Fog`), HemisphereLight + DirectionalLight с тенями (shadow map 2048, тени только у машин и декора).
- Большая плоскость-земля (трава, тёмно-зелёная).
- Декор через `InstancedMesh`: ~300 деревьев (конус+цилиндр) случайно, но **не ближе 14 м к центру трассы** (проверять по сэмплам); неоновые фонари вдоль трассы каждые ~40 сэмплов.
- `renderer.setPixelRatio(min(devicePixelRatio, 2))`, обработка resize.

## 11. Управление (`input.js`)

| Клавиша | Действие |
|---|---|
| W / ↑ | газ |
| S / ↓ | тормоз / задний ход |
| A D / ← → | руль (плавное нарастание steer к цели со скоростью 6/с) |
| Пробел | ручник (дрифт) |
| R | вернуть машину на трассу |
| C | смена камеры |
| Esc / P | пауза |

## 12. Звук (`audio.js`)

Два осциллятора (sawtooth + square) через lowpass-фильтр и gain; частота `60 + speedRatio*180 Гц`. Создаётся после первого клика по «Старт». Кнопка M — mute. Ошибки AudioContext не должны ломать игру.

## 13. Порядок реализации (этапы)

1. `index.html` + `style.css` + `world.js` + `main.js`: пустая сцена рендерится.
2. `track.js`: трасса видна, стартовая линия, отбойники.
3. `car.js` + `input.js` + `camera.js`: машина ездит, дрифтит, упирается в стены.
4. `race.js` + `hud.js`: круги, время, финиш, меню и отсчёт.
5. `ai.js`: 3 бота, столкновения машин, места.
6. Мини-карта, декор, звук, полировка, README.
7. `tests/smoke.mjs` и прогон.

## 14. Критерии готовности

- Страница открывается без ошибок в консоли.
- Игрок может пройти 3 круга, увидеть экран финиша и начать заново.
- Боты проходят трассу без застреваний, занимают разные места.
- Нельзя засчитать круг, срезав трассу или проехав финиш задом.
- 60 FPS на обычном ноутбуке (тени только где нужно, InstancedMesh для декора).
