# 3D-игры и 3D-модели (Three.js + cannon-es)

Цель — быстро выдать **рабочую, красивую, играбельную** 3D-игру одним файлом `index.html`,
который открывается в браузере без сборки и без сервера ассетов.

## Стек (фиксированные версии)

- Рендер: `three@0.160.0` (ES-модули через import map с jsDelivr)
- Физика: `cannon-es@0.20.0`
- Аддоны three: `three/addons/` → `https://cdn.jsdelivr.net/npm/three@0.160.0/examples/jsm/`
- Без внешних моделей и текстур: всё процедурно (геометрия + `CanvasTexture`) — так игра не ломается из‑за CORS/битых ссылок.

## Порядок работы

1. **Уточни жанр одной строкой**, только если запрос совсем пустой. Иначе выбери сам и сделай.
2. **Начни с шаблона** `templates/game-template.html` (скопируй, не пиши с нуля). В нём уже есть:
   рендерер с тенями и тонмаппингом, свет, небо/туман, физический мир, связка «меш ↔ тело»,
   фиксированный шаг физики, управление WASD/пробел/мышь (pointer lock), HUD, пауза, ресайз.
3. **Модели** строй по правилам из `reference/models.md` (группы из примитивов, скругления,
   материалы PBR, процедурные текстуры, инстансинг для массовых объектов).
4. **Физику** — по `reference/physics.md` (типы тел, материалы трения/упругости, контакты,
   транспорт с `RaycastVehicle`, триггеры, сочленения).
5. **Игровой цикл**: цель, счёт, проигрыш/победа, рестарт (`R`), нарастающая сложность.
   Игра без цели — не игра.
6. **Полировка** (минимум 3 пункта): частицы при ударах/сборе, тряска/плавная камера,
   звуки через WebAudio (генерация осцилляторами, без файлов), всплывающий текст, вспышки эмиссии.
7. **Проверка**: запусти headless-скриншот (раздел ниже), убедись, что консоль без ошибок и
   на кадре видна сцена, а не чёрный экран. Исправь и перепроверь.
8. Сохрани в `games/<имя-игры>/index.html` (если пользователь не указал другое место) и
   кратко опиши управление.

## Обязательные правила качества

- `renderer.setPixelRatio(Math.min(devicePixelRatio, 2))`, `outputColorSpace = SRGBColorSpace`,
  `toneMapping = ACESFilmicToneMapping`, `shadowMap.type = PCFSoftShadowMap`.
- Физика — фиксированным шагом: `world.step(1/60, dt, 3)`; `dt` ограничивай `Math.min(dt, 0.1)`.
- Каждый объект: одна функция-фабрика, возвращающая `{ mesh, body }`; синхронизация в одном месте.
- Тени: `castShadow`/`receiveShadow` только где видно; у направленного света подгони `shadow.camera` под арену.
- Производительность: ≤ ~200 динамических тел, `InstancedMesh` для повторов, переиспользуй
  геометрии и материалы, удаляй тела из мира и меши из сцены (`geometry.dispose()`) при уничтожении.
- Управление работает и без pointer lock (клик по canvas — захват; Esc — пауза).
- Мобильные: если `matchMedia('(pointer: coarse)')` — показать простые экранные кнопки.
- Никаких бесконечных `while`, никакого `alert()`.

## Быстрые рецепты по жанрам

| Жанр | Ключевое |
|---|---|
| Платформер 3-го лица | капсула/сфера игрока с `fixedRotation`, проверка земли лучом вниз, прыжок импульсом, камера-пружина за спиной |
| FPS / тир | `PointerLockControls`-подобный обзор, луч `Raycaster` из центра экрана, отдача, мишени-тела с импульсом в точку попадания |
| Гонки | `CANNON.RaycastVehicle`, 4 колеса, `applyEngineForce`/`setSteeringValue`/`setBrake`, трасса из сегментов, чекпоинты-триггеры |
| Песочница / разрушение | стена из ящиков, пушка шарами, `sleep` для покоящихся тел, кнопка спавна |
| Боулинг / бильярд / мини-гольф | материалы с `restitution`, сила по удержанию кнопки, индикатор мощности |
| Сборщик монет / раннер | триггеры `collisionResponse=false`, процедурная генерация впереди, удаление позади |

## Только 3D-модель (без игры)

Если просят «просто модель»: та же база шаблона, но без физики игрока — `OrbitControls`,
поворотный стол, студийный свет (ключевой + заполняющий + контровой), `RoomEnvironment` для
отражений, пол с мягкой тенью. Модель — фабрика `createX()` с параметрами (цвет, размер, детализация),
чтобы её можно было переиспользовать в игре. По запросу — экспорт в `.glb` через `GLTFExporter`
(кнопка «Скачать GLB»).

## Проверка скриншотом

```bash
NODE_PATH=$(npm root -g) node .claude/skills/3dgames/scripts/screenshot.mjs games/<имя>/index.html /tmp/shot.png
```

Скрипт открывает страницу в Chromium (Playwright), ждёт 2 с, сохраняет скриншот и печатает
ошибки консоли. Нет Playwright — пропусти шаг и скажи об этом пользователю.

## Чего не делать

- Не воссоздавать конкретные существующие игры (названия, персонажи, уровни, узнаваемый стиль) —
  делать оригинальные игры в жанре.
- Не тянуть модели/текстуры с внешних сайтов.
- Не использовать устаревшие `three/examples/js` и глобальный `THREE` из `<script>`.
