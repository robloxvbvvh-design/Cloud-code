# ИИ Видео

Скилл для полного цикла производства видео: **исходники → расшифровка → монтаж/графика → рендер → финальная обработка**.

## Плагины (инструменты)

| Плагин | Для чего | Инструкция |
|---|---|---|
| **yt-dlp** | Скачать видео/аудио/субтитры с YouTube и других сайтов | [plugins/yt-dlp.md](plugins/yt-dlp.md) |
| **Whisper** | Распознавание речи → текст, субтитры SRT/VTT с таймкодами | [plugins/whisper.md](plugins/whisper.md) |
| **FFmpeg** | Нарезка, склейка, конвертация, сжатие, вшивание субтитров, звук | [plugins/ffmpeg.md](plugins/ffmpeg.md) |
| **Remotion** | Видео на React: анимации, титры, шаблоны, рендер в MP4 | [plugins/remotion.md](plugins/remotion.md) |
| **HyperFrames** | Видео из HTML/CSS/JS (GSAP), удобно для генерации ИИ | [plugins/hyperframes.md](plugins/hyperframes.md) |

Перед работой с плагином — прочитай его файл в `plugins/`.

## Как выбрать инструмент

- Нужно **скачать** исходник → `yt-dlp`.
- Нужен **текст или субтитры** из речи → `Whisper`.
- Простая операция над готовым файлом (обрезать, склеить, сжать, 9:16, наложить звук) → `FFmpeg`.
- Нужна **моушн-графика / шаблон** на React, переиспользуемые компоненты, данные из JSON → `Remotion`.
- Нужно быстро собрать ролик из **HTML-сцены** (ИИ пишет HTML лучше всего) → `HyperFrames`.

## Стандартный пайплайн (пример: Shorts из длинного видео)

1. **Скачать**: `yt-dlp -f "bv*+ba/b" --merge-output-format mp4 -o "src.%(ext)s" "<URL>"`
2. **Расшифровать**: `whisper src.mp4 --model medium --language ru --output_format srt`
3. **Найти лучший фрагмент** по тексту расшифровки (ищи хук, законченную мысль, 15–60 сек).
4. **Вырезать и сделать 9:16** через FFmpeg (см. `plugins/ffmpeg.md`).
5. **Оформить**: титры/анимированные субтитры через Remotion или HyperFrames, либо просто вшить SRT через FFmpeg.
6. **Финал**: нормализация громкости (`loudnorm`), H.264 + AAC, `-movflags +faststart`.

## Правила

1. **Проверяй окружение** перед стартом: `ffmpeg -version`, `yt-dlp --version`, `whisper --help`, `node -v` (Remotion/HyperFrames требуют Node.js 18+). Чего нет — установи (см. файлы плагинов).
2. **Не трогай оригиналы**: всё промежуточное — в папку `work/`, результат — в `output/`.
3. **Сначала превью**: прежде чем рендерить весь ролик, отрендери 3–5 секунд или один кадр и проверь.
4. **Форматы по умолчанию**: MP4, H.264 (`libx264`, `-crf 18–23`), AAC 192k, 30 fps. Вертикаль 1080×1920, горизонталь 1920×1080, квадрат 1080×1080.
5. **Авторские права**: скачивай и используй только контент, на который у пользователя есть права (свой, лицензированный, CC). Соблюдай правила площадок.
6. **Отчитывайся**: в конце укажи путь к результату, длительность, разрешение и размер файла (`ffprobe`).
