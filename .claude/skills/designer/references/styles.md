# Пресеты стилей

Это ориентиры по **эстетике**, а не копии брендов. Логотипы, фирменные
названия продуктов и тексты не воспроизводим.

---

## «Как у Apple» — премиальный минимализм
- **Характер:** много воздуха, огромные заголовки, один акцент, продукт в центре.
- **Светлая:** фон `#FFFFFF`, поверхность `#F5F5F7`, текст `#1D1D1F`,
  вторичный `#6E6E73`, граница `#D2D2D7`, акцент `#0071E3`.
- **Тёмная:** фон `#000000`, поверхность `#1D1D1F`, текст `#F5F5F7`,
  вторичный `#A1A1A6`, акцент `#2997FF`.
- **Шрифт:** системный `-apple-system` / Inter; заголовки 56–96px,
  weight 600–700, `letter-spacing: -0.02em`.
- **Форма:** радиус 18–28px у карточек, кнопки-«пилюли» (980px), почти без теней.
- **Сетка:** секции на всю ширину по 100vh, контент по центру, max-width ~980px.
- **Движение:** мягкие fade/slide при скролле, `cubic-bezier(.25,.1,.25,1)`.
- **Текст:** короткие слоганы («Мощь. В новом облике.»), ссылки «Подробнее ›».

## «Как Stripe» — финтех с градиентами
- Фон `#FFFFFF`/`#F6F9FC`, текст `#0A2540`, вторичный `#425466`,
  акцент `#635BFF`; яркий диагональный mesh-градиент
  (`#FF80B5 → #9089FC → #00D4FF`) в hero.
- Шрифт: Inter / system, заголовки 48–64px, weight 700.
- Скос секций (`clip-path` или `skewY(-6deg)`), тени `0 30px 60px -12px rgba(50,50,93,.25)`.

## «Как Linear» — тёмный tech
- Фон `#08090A`, поверхность `#141516`, граница `rgba(255,255,255,.08)`,
  текст `#F7F8F8`, вторичный `#8A8F98`, акцент `#5E6AD2`.
- Шрифт: Inter, заголовки с градиентом текста (белый → серый), weight 500–600.
- Тонкие 1px-границы, свечения (radial-gradient), радиус 8–12px, сетка-фон.

## «Как Notion» — тёплый минимализм
- Фон `#FFFFFF`, текст `#37352F`, вторичный `#787774`, граница `#E9E9E7`,
  мягкие подсветки (`#FBF3DB`, `#E7F3F8`, `#FBE4E4`), акцент `#2383E2`.
- Шрифт: system / Inter, умеренные размеры, emoji и простые линейные иконки.
- Радиус 4–6px, без теней, много списков и блоков.

## Глассморфизм
- Яркий градиентный фон (`#667EEA → #764BA2` или неоновые пятна blur).
- Карточки: `background: rgba(255,255,255,.12); backdrop-filter: blur(20px);
  border: 1px solid rgba(255,255,255,.25)`, радиус 20–24px.
- Белый текст, тонкие шрифты (Inter 300–500).

## Необрутализм
- Фон `#FFFDF5`, жирные чёрные рамки 3px `#000`, жёсткие тени `6px 6px 0 #000`.
- Кислотные акценты: `#FFDE59`, `#FF6B6B`, `#4ECDC4`, `#A78BFA`.
- Шрифт: Space Grotesk / Archivo Black, крупно, без скруглений или 8px.

## Ретро 90-х / Y2K
- Хромированные градиенты, `#00FFFF`, `#FF00FF`, `#C0C0C0`, пиксельные рамки.
- Шрифты: VT323, Press Start 2P (для акцентов), Comic-подобные — дозированно.

## Люкс / премиум-бренд
- Фон `#0E0E0E` или `#F7F4EE`, текст `#EDE6D6` / `#1A1A1A`, акцент золото `#C9A96E`.
- Шрифт: Playfair Display / Cormorant для заголовков + Inter для текста,
  капс с `letter-spacing: .2em` в подписях. Тонкие линии, много воздуха.

## Material-подобный
- Фон `#FFFBFE`, primary `#6750A4`, surface-контейнеры `#F3EDF7`,
  текст `#1C1B1F`. Roboto. Радиусы 12–28px, тональные поверхности вместо теней.

---

## Если стиля нет в списке
Выведи пресет сам по осям: **характер → палитра (светлая/тёмная) → шрифт →
форма (радиусы/тени/границы) → сетка → движение → тон текста**,
и оформи так же, как выше.
